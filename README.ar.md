# محرك إعداد وتوزيع Claude Code (بواسطة Rust)

هذا المشروع عبارة عن محرك تثبيت عالي الأداء يعتمد على لغة Rust، يتيح لك إعداد بيئة **Claude Code** التابعة لك في ثوانٍ. يدير النظام الإعدادات، وإعدادات سلسلة الأدوات (toolchain)، وإدارة خوادم MCP، والتدقيق الأمني من خلال ملف تنفيذي محلي واحد.

## 🚀 الميزات الرئيسية
- **محرك Rust كامل:** يعمل مباشرة عبر ملف تنفيذي دون الاعتماد على سكربتات Bash.
- **توزيع آمن:** حماية تلقائية للأفرع (branch protection) وخطافات commit مسبقة (pre-commit hooks).
- **إدارة MCP شاملة:** إعداد تلقائي لـ 19 خادم MCP جاهز للاستخدام.
- **ذاكرة ذكية:** إدارة ملاحظاتك عبر نظام بحث سريع قائم على SQLite.

## 📦 التثبيت
1. قم بالبناء: `cargo build --release`
2. التثبيت: `./target/release/claude-code-setup.exe install`

## 🛠️ الأوامر
- `install`: يبدأ التثبيت الكامل.
- `update`: تحديث الإعدادات.
- `test`: اختبارات التشخيص والتحقق.
- `memory-search <كلمة>`: البحث في ملاحظات الذاكرة.

## 🛡️ الأمن
- **حماية الأفرع:** تمنع الالتزامات (commits) المباشرة على الفروع الرئيسية (main/master).
- **ماسح الأسرار:** يمنع تضمين مفاتيح API المشفرة داخل الكود.
