# Claude Code Complete Setup (محرك Rust بنسبة 100%)

هذا المشروع عبارة عن نظام نشر وإدارة عالي الأداء يعتمد **بنسبة 100% على لغة Rust** لبيئة **Claude Code**.

تمت إزالة جميع سكربتات Bash (`.sh`) و Python (`.py`) القديمة بالكامل وتحويلها إلى برنامج تنفيذي محلي واحد بلغة Rust (`claude-code-setup.exe`).

## 🚀 الاختلافات عن النسخة الأصلية

1. **بنية Rust خالصة 100%:** إلغاء كافة الاعتمادات على Shell و Python.
2. **تطبيع المسارات تلقائياً:** تحويل مسارات Linux الثابتة مثل `/home/jb_remus` تلقائياً إلى بيئة المستخدم المحلية.
3. **محرك ذاكرة قائم على SQLite:** فهرسة ملاحظات الذاكرة في قاعدة بيانات SQLite مدمجة للبحث الفوري.
4. **وكيل ذاتي وأمن مدمج:** إدارة حماية الأفرع وخطافات Git مباشرة عبر محرك Rust.

## 📦 التثبيت والاستخدام
```bash
# البناء
cargo build --release

# التثبيت
./target/release/claude-code-setup.exe install

# تشغيل الاختبارات
./target/release/claude-code-setup.exe test
```

## 🛠️ الأوامر
- `install`: الإعداد والتكوين الكامل.
- `update`: تحديث التكوينات.
- `test`: التحقق من صحة التثبيت.
- `mcp-list`: سرد خوادم MCP.
- `memory-index`: فهرسة الذاكرة في SQLite.
- `memory-search <كلمة>`: البحث السريع في الذاكرة.
- `security-audit`: تدقيق الأمن وحالة Git.
- `agent-workflow`: تشغيل سير عمل الأفرع المستقل.
